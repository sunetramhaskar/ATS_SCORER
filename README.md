# AI Resume ATS Scorer

An AI-powered Applicant Tracking System (ATS) that analyzes resumes against job descriptions and evaluates how well a candidate's resume matches the target role.

## Features

- Resume parsing from PDF and DOCX
- Job description analysis
- ATS compatibility scoring
- Keyword matching
- BERT-based semantic similarity
- Missing keyword identification
- Resume feedback and recommendations
- AI-powered feedback using Groq LLM
- Resume analysis report generation

## Tech Stack

- Python
- FastAPI
- Streamlit
- BERT
- spaCy
- scikit-learn
- Groq LLM
- Supabase
